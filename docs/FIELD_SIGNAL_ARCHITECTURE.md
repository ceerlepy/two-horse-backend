# Field / Surface Compatibility Signal

The model's `field` component uses two independent sources.

## 1. TJK exact-condition history

For every canonical race, TJK exposes a
`Detaylı At Karşılaştırma` URL.

The URL is generated by TJK and contains:

- venue
- race code
- current distance
- current surface

The resulting page contains historical runner performances under
those conditions.

Acquisition:

HTTP
-> CF_SCRAPE
-> CF_CONTENT
-> last-good D1

The source is fetched once per race, not once per horse.

Field score uses recent exact-condition finishing performance.

Small historical samples are shrunk toward neutral rather than
treated as highly certain.

## 2. Expert comments

Expert comments contribute only when they contain explicit
surface/pist/mesafe language.

Generic positive horse commentary does not become a field signal.

## Combination

When both exist:

- TJK exact-condition history: 75%
- explicit expert field signal: 25%

When only one exists, that signal may be used alone.

Missing field evidence remains null.

Scoring's normal missing-component reweighting then applies.
